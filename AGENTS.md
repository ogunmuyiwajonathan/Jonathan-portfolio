# AGENTS.md — Jonathan Portfolio

## Stack

Vite 7 + React 19 + TypeScript 5.9 + Tailwind CSS v3 + React Router v7 + Framer Motion 12.

## Commands

| Command | What it does |
|---------|-------------|
| `npm run dev` | Start Vite dev server |
| `npm run build` | **`tsc -b` first, then `vite build`** — TS errors block the build |
| `npm run lint` | ESLint (flat config, `eslint.config.js`) |
| `npm run preview` | Vite production preview |
| `node scripts/convert-images.mjs` | Convert PNG/JPG in `public/images/` to WebP (requires `sharp`) |

No test runner is configured.

## Project structure

```
src/
  App.tsx          — Router, loading screen, GA tracker
  main.tsx         — Entrypoint
  index.css        — Tailwind layers, oklch CSS vars, scrollbar, keyframes
  lib/utils.ts     — cn() helper (clsx + tailwind-merge)
  hooks/
    usePageTitle.ts — document.title hook (no deps)
  components/
    Layout.tsx      — Nav, footer, mobile menu, particles, cursor spotlight, scroll-to-top
    Particles.tsx   — OGL WebGL particle system
    CursorSpotlight.tsx, PageProgress.tsx, LoadingScreen.tsx, ScrollReveal.tsx, CountUp.tsx, Skeleton.tsx, ProjectModal.tsx, SlickDropdown.tsx
    react-bits/     — BlurText, SplitText, FuzzyText, SpotlightCard
  pages/            — Home, About, Works, Contact, NotFound
public/
  images/           — WebP images (generated by scripts/convert-images.mjs)
  sitemap.xml       — Static, 4 routes
  robots.txt
```

## Key quirks & gotchas

- **`@` path alias** ? `src/` (configured in `vite.config.ts` + `tsconfig.json`)
- **Color mismatch**: CSS vars are defined as `oklch()` in `index.css`, but `tailwind.config.js` references them via `hsl(var(--...))`. Colors may look different than expected.
- **Two fonts loaded**: `Inter` (Google Fonts, likely unused) + `Geist Variable` (`@fontsource`, active). Geist is the body font.
- **Dark mode**: Class strategy (`darkMode: ["class"]`), driven by `localStorage` in `App.tsx` — defaults to dark.
- **TypeScript strict**: `noUnusedLocals`, `noUnusedParameters`, `verbatimModuleSyntax`, `erasableSyntaxOnly` all enabled. Use `import type` for type-only imports. No `enum` or `namespace`.
- **GA tracking**: `G-7FVH9XHPMP` — gtag snippet in `index.html`, SPA route-tracking via `AnalyticsTracker` in `App.tsx`.
- **Vercel**: SPA rewrites in `vercel.json` explicitly exclude `/sitemap.xml` and `/robots.txt`. Sitemap gets explicit `Content-Type: application/xml`.
- **Image pipeline**: Source images with `.original.ext` suffix in `public/images/` ? run `node scripts/convert-images.mjs` to produce WebP variants.
- **Dead deps present**: `radix-ui`, `class-variance-authority`, `shadcn`, `tw-animate-css`, `tailwindcss-animate` — likely unused. Be cautious removing; verify no imports first.
- **Test artifacts in git**: `.playwright-mcp/` directory and `portfolio-home-viewport.png` are committed.
- **`.playwright-mcp/`**: Generated by the Playwright MCP browser tool during sessions. Git-tracked but not source code.
- **2-second loading screen**: `LoadingScreen.tsx` forces a 2s minimum display via `setTimeout` in `App.tsx` — blocks content visibility.
- **Bundle**: ~577 KB (185 KB gzipped). No route-level code splitting.
- **No env files**: No `.env`, no production domain config. Domain is `jonworld.vercel.app` (hardcoded in sitemap.xml).
